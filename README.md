# Creature Story Mixer

Creature Story Mixer is a browser-based classroom tool for Creature Studio. Each student enters details about their own creature, its real Hummingbird or micro:bit sense-think-act setup, and a collection of secret silly words. The site selects one of 20 solo adventures and creates a personalized read-aloud story.

## Features

- 20 randomized solo-adventure story structures
- Real sensor, output, and programmed-response details in every story
- Grammar-safe Sense-Think-Act presentation
- Surprise Me word generator
- New story with the same words
- One-click branded PDF download
- Copy and print controls
- Responsive layout for student MacBooks
- No login, tracking, external requests, or stored student data

## Privacy

All story generation and PDF creation happen locally in the visitor's browser. Student entries are not uploaded or saved.

## Run locally

Open `index.html` in a modern browser or serve this folder with any static web server.
